# bank

Учебный проект на Go: банковская платёжная система с пользователями, балансами и
переводами между счетами. Основная цель — разобрать разделение проекта на пакеты,
`map` как хранилище, передачу указателей и **конкурентную обработку транзакций
через каналы и пул воркеров**.

## Возможности

- Регистрация пользователей в платёжной системе.
- Хранение пользователей и истории транзакций.
- Пополнение счёта — `Deposit`.
- Снятие средств — `Withdraw`, с проверкой баланса.
- Перевод между счетами — `ProcessingTransactions`.
- Параллельная обработка очереди транзакций: буферизованный канал + пул воркеров.
- Возврат ошибки, если денег не хватает или пользователь не найден.

## Структура проекта

```
bank/
├── cmd/
│   └── app/
│       └── main.go                  # точка входа, сборка канала и воркеров
├── internal/
│   ├── domain/
│   │   └── domain.go                # доменная модель: User, Transaction
│   └── bank/
│       ├── bank.go                  # PaymentSystem — состояние системы
│       ├── pay.go                   # Deposit, Withdraw — операции над счётом
│       └── transactions.go          # AddUser, AddTransaction, ProcessingTransactions
├── go.mod
└── README.md
```

`internal/` — внутренние пакеты: импортировать их из другого модуля нельзя.

- `domain` — только данные, без поведения.
- `bank` — хранилище пользователей и вся логика операций.
- `cmd/app` — точка входа: собирает очередь, создаёт канал, запускает воркеров.

## Требования

- Go 1.26.4 или новее

```bash
go run ./cmd/app
```
