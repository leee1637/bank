# bank

Небольшой учебный проект на Go: банковская платёжная система с пользователями,
балансами и переводами между счетами. Цель — пощупать разделение проекта на
пакеты, `map` как хранилище, передачу указателей и возврат ошибок.

## Возможности

- Регистрация пользователей в платёжной системе.
- Хранение пользователей и истории транзакций.
- Пополнение счёта — `Deposit`.
- Снятие средств — `Withdraw`, с проверкой баланса.
- Перевод между счетами — `ProcessingTransactions`.
- Возврат ошибки, если денег не хватает или пользователь не найден.

## Структура проекта

```
bank/
├── cmd/
│   └── app/
│       └── main.go                  # точка входа, демонстрация работы
├── internal/
│   ├── domain/
│   │   └── domain.go                # доменная модель: User, Transaction
│   └── bank/
│       ├── bank.go                  # PaymentSystem — состояние системы
│       ├── pay.go                   # Deposit, Withdraw — операции над счётом
│       └── transactions.go          # работа с транзакциями
├── go.mod
└── README.md
```

`internal/` — внутренние пакеты: импортировать их из другого модуля нельзя.

- `domain` — только данные, без поведения.
- `bank` — вся логика: хранилище пользователей, операции, обработка переводов.
- `cmd/app` — точка входа, здесь собирается всё вместе.

## Требования

- Go 1.26.4 или новее

## Запуск

```bash
go run ./cmd/app
```
