# bank V1

Небольшой учебный проект на Go: банковский счёт с базовыми операциями пополнения
и снятия. Сделан, чтобы потренировать структуру проекта, встраивание структур, работу с указателями и возвращение ошибок.

## Возможности

- Создание пользователя банка с балансом.
- Пополнение счёта — `Deposit`.
- Снятие средств — `Withdraw`, с проверкой баланса.
- Возвнение ошибки, если денег на счёте не хватает.

## Структура проекта

```
bank/
├── cmd/
│   └── app/
│       └── main.go      # точка входа, демонстрация работы
├── internal/
│   ├── domain/
│   │   └── domain.go    # доменная модель (User)
│   └── pay/
│       └── pay.go       # бизнес-логика операций (Deposit, Withdraw)
├── go.mod
└── README.md
```


## Требования

- Go 1.26.4 или новее

## Запуск

```bash
go run ./cmd/app
```
